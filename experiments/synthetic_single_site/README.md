# synthetic_single_site

Single-site RWMH calibration on synthetically generated NEE observations.

This is a **pipeline test**, not a real flux-tower analysis. SIPNET is run at
known parameter values ("ground truth") to produce synthetic NEE, Gaussian
noise is added, and we calibrate to check parameter recovery.

## Quick start

```bash
# 1. Generate data (climate slice + synthetic observations)
python config.py

# 2. Run MCMC
python run_mcmc.py --run_id rwmh_v1

# 3. Explore in notebooks
jupyter lab notebooks/
```

## Structure

```
config.py               ← single source of truth for this experiment
run_mcmc.py             ← MCMC script; saves ArviZ NetCDF to outputs/mcmc/
data/
    climate.clim        ← 3-year ERA5 climate slice (generated by config.py)
    obs_nee.npy         ← synthetic noisy NEE timeseries (generated by config.py)
outputs/
    mcmc/
        <run_id>.nc     ← ArviZ InferenceData NetCDF
notebooks/
    notebook_env.py     ← sys.path shim (import at top of every notebook)
    make_notebooks.py   ← regenerate notebooks from source
    01_prior_predictive.ipynb
    02_mcmc_diagnostics.ipynb
```

## Calibrated parameters

8 SIPNET parameters (defined in `config.py::build_prior()`):

| Parameter       | Prior             | Ground truth |
|-----------------|-------------------|-------------|
| a_max           | LogNormal(ln120, 0.5) | 120.0   |
| psn_t_opt       | Normal(20, 8)     | 20.0        |
| half_sat_par    | LogNormal(ln200, 0.5) | 200.0   |
| base_veg_resp   | LogNormal(ln0.5, 0.5) | 0.5     |
| veg_resp_q10    | LogNormal(ln2.0, 0.3) | 2.0     |
| base_soil_resp  | LogNormal(ln0.3, 0.5) | 0.3     |
| soil_resp_q10   | LogNormal(ln2.2, 0.3) | 2.2     |
| wue_const       | LogNormal(ln10, 0.5)  | 10.0    |

## Notes

- `sigma_obs = 2.0` gC m⁻² per 3-hr step represents temporal autocorrelation
  and structural model error. A smaller value would over-tighten the likelihood
  and produce very low RWMH acceptance rates for 8760 sub-daily observations.
- `a_max` and `half_sat_par` are partially non-identifiable (both scale GPP).
  Expect correlated posterior and slower mixing for these parameters.
- The prior is the sole source of truth for which parameters are calibrated.
  `config.py::build_prior()` returns a `ProductDistribution`; parameter names
  are derived from `prior.record_template.fields`.
