One probability layer for the prior and the observation model

A proposal to generalize the parameter layer PR #72 merged into a small probability layer, independent of this project. A user declares a model in specs. The specs are bound to the labels in use, which gives a distribution. That distribution is evaluated, draw by draw, as ordinary laws from TFP and EnsKit. Conditioning it on the data gives the target every inference algorithm reads.

Date 2026-10-04 (revision 5) Base origin/main at ec21aa9 (PR #72) References ProbPipe design/ at PR #467; EnsKit redesign at pyEKI a9e2faf Status being implemented; the handoff document records which PRs have landed

1Summary

Today the package says what is believed about the parameters, but not what is believed about the data. Prior is a factored density over one vector. The observation side has a vector and its operators, but no distribution, so the experiment writes the noise model, the likelihood and every algorithm's glue by hand.

The proposal replaces sipnet_calibration.parameters with sipnet_calibration.probability, built on one idea: a model is a product of conditional laws over named components, some of which are computed from others. Conditioning a model on the values of some components gives a target over the rest. A model passes through three stages, and the names say which stage an object belongs to:

  1. Declare. A user writes specs, which hold no labels and no numbers. Every declaration class ends in Spec:
    • ArraySpec: what a component is;
    • FactorSpec: a conditional law;
    • GaussianSpec and the covariance specs: a structured Gaussian law;
    • DeterministicSpec: a traced function.
    A Simulator, the forward model, is the one part that is real code rather than a declaration. joint(*parts, inputs=...) collects the parts, and declares the inputs, into a ModelSpec.
  2. Bind. model_spec.bind(coords=...) gives the labels of every dim (which sites, which observations) and returns a FactoredDistribution.
  3. Evaluate. At each draw, each factor spec becomes an ordinary law:
    • a TFP distribution for a prior;
    • an EnsKit Gaussian with enskit.linalg covariance operators for a noise model.
    model.law(name, given=...) returns that law for inspection.

condition_on(model, observed) applies Bayes' rule to a bound model and gives a Posterior, the one object every inference adapter reads. It provides:

  • the layout of theta;
  • the prior's sampler and density;
  • a batched log likelihood that runs the simulator once per batch and scores failed samples -inf;
  • the Gaussian structure EKI needs;
  • closed-form full conditionals for Gibbs steps;
  • a traced density for gradients in whatever no simulator reads.

The adapter layer gets thinner:

  • The forward model becomes a Simulator. It no longer sees theta, the vector or the derived parameters.
  • The observation vector supplies the observed components, their per-observation constants, and a one-line noise factor per source (noise_factor).
  • The algorithm adapters (EnsKit/pyEKI, SMC, MCMC) move to a new generic inference package.

The vocabulary follows ProbPipe's where its design is settled: component, factor (always a law), event, given, FactoredDistribution, condition_on, batch dim sample. The Gaussian and the linear algebra are EnsKit's: a covariance spec evaluates to an enskit.linalg operator, and a Gaussian factor to an EnsKit Gaussian.

3What is wrong today

The parameter layer PR #72 merged is sound for what it does. The trouble is that it is a prior engine, the inference problem is a joint model, and everything between the two is written by hand. The PR #69 experiment at 7949640 is the evidence; the F-numbers are from the survey of it.

F12. The Gaussian density exists five times, and nothing scores a failed sample.

No target for samplers

Two structural causes lie behind these. First, the prior and the likelihood are different kinds of object: one is a declarative, checked, traced density, the other whatever the experiment writes. Second, the forward model sits on the wrong side of the seam: it takes theta and converts it itself, so it must know the vector, the derived parameters and theta's layout.

4The probabilistic model

This section defines the model mathematically, independent of any application: the graph, what binding does to it, and what conditioning does to it (§4.1–§4.8). §4.9 then maps this project's calibration onto the definitions.

4.2 Components and their labels

A component is a named array a draw of the model holds. Its ArraySpec says what its values are and which axes it has. There are two kinds of axes, and their labels come from different places:

AxesWhat they areLabels come fromChange?
element axesthe axes of one value: the four parts of an allocation simplex, the rows and columns of a covariance matrixthe ArraySpec (element_axes), since they are part of what the value isnever
indexed_by dimsthe dims the value is replicated over: one value per site, per PFTthe coords, {dim: labels}, given to bindwith each bind

A component's block is all its values. Its shape is (*[len(coords[d]) for d in indexed_by], *element shape). Two kinds of fixed data sit on the same axes, and functions read them:

  • a constant, a value per label, such as a covariate per site or a measurement standard deviation per observation;
  • a label map, which sends each label of one dim to a label of another dim or element axis, such as each site to its PFT. A function receives it as integer positions.

A dim whose labels are a pandas.MultiIndex is a stacked dim. It is how a ragged set of labels becomes one dim, such as the (site, time) pairs an observation source observes. A level of a stacked dim may be named wherever a dim may be: in a selector, and as the grouping of a block-diagonal covariance.

4.3 The model graph

Definition 1 (model). A model is a directed acyclic graph \(G = (V, E)\) whose nodes are its parts and its inputs, \[ V = R \sqcup D \sqcup U, \] with an edge \(w \to v\) when part \(v\) reads a component of \(w\). Write \(\mathrm{pa}(v)\), \(\mathrm{an}(v)\) and \(\mathrm{de}(v)\) for the parents, ancestors and descendants of \(v\). Each node has a value \(z_v \in \mathcal Z_v\): the tuple of the blocks of the components it declares.

  • Random nodes \(v \in R\) are the factors (FactorSpec). Each carries a Markov kernel with density \(p_v(z_v \mid z_{\mathrm{pa}(v)})\) against a reference measure \(\lambda_v\) on \(\mathcal Z_v\): Lebesgue measure per number on an interval, on the first \(k-1\) coordinates on the simplex, on the lower triangle for a positive-definite matrix.
  • Deterministic nodes \(v \in D\) are the DeterministicSpecs and Simulators. Each carries a map \(f_v : \mathcal D_v \to \mathcal Z_v\) on a domain \(\mathcal D_v \subseteq \mathcal Z_{\mathrm{pa}(v)}\), which is all of \(\mathcal Z_{\mathrm{pa}(v)}\) except for a simulator that can fail.
  • Input nodes \(v \in U\) are declared by joint(..., inputs=). They have no parents and carry nothing; their values are supplied.

Any node may read any other kind, inputs included: a deterministic node that reads only inputs is a fixed computed value.

The graph is not stored. It is derived from the names each part's functions read (the keyword rule, §7.3), and its edges are acyclic by construction or refused.

Proposition 1 (the joint law). Extend each partial map by a value \(\bot\) off its domain, \(\bar f_v = f_v\) on \(\mathcal D_v\) and \(\bot\) elsewhere, and let every node that reads \(\bot\) take the value \(\bot\) (a kernel puts its mass there). Since \(G\) is acyclic, each deterministic value is then a function of the random and input values, \(z_D = F(z_R, z_U)\), computed in topological order. Given inputs \(u\), the random values have the joint density \[ p(z_R \mid u) \;=\; \prod_{v \in R} p_v\big(z_v \mid z_{\mathrm{pa}(v)}\big) \qquad \text{against } \lambda_R = \textstyle\bigotimes_{v\in R} \lambda_v, \] with every deterministic and input value substituted, on \(\mathcal Z_R\) extended by \(\bot\). Ancestral sampling in topological order draws from it.

A deterministic node therefore adds nothing to the density: it is a change of what each kernel reads, not a factor. Equivalently, the joint law of all of \(z_R, z_D\) is \(\prod_{v\in R} p_v \prod_{v \in D} \delta\big(z_v - f_v(z_{\mathrm{pa}(v)})\big)\).

4.4 Binding

Binding makes the model one distribution.

  • Coords. The coords fix every value space: a component's block shape is the number of labels of each indexed_by dim, by its element shape. Constants and label maps are read at those labels.
  • Inputs. The inputs are set to values \(u_0\).

The result is the distribution

\[ P \;=\; p(\,\cdot \mid u_0) \quad \text{on } \mathcal Z_R . \]

A FactoredDistribution is \(P\): sample draws from it ancestrally, and log_prob evaluates its density. An input is part of the model's declaration, because parts read it. Its value is part of binding, because it is fixed data, like the labels.

4.5 Conditioning

Conditioning is Bayes' rule, and nothing else. Let \(O \subseteq R\) be the observed nodes, with values \(y = (y_v)_{v\in O}\). Two sets of the remaining nodes are determined by the graph alone:

Definition 2 (barren nodes, target). The barren nodes are the unobserved random nodes with no observed descendant, \[ B \;=\; \{\, v \in R \setminus O \;:\; \mathrm{de}(v) \cap O = \varnothing \,\}, \] descendants taken through deterministic nodes as well. The target is the rest, \(T = R \setminus (O \cup B)\), and its components are the parameters. When nothing is observed there is nothing to prune toward: by convention \(B = \varnothing\) and \(T = R\), so conditioning on nothing gives the prior over every random node.

Proposition 2 (barren nodes drop out). The posterior factors as \[ p(z_T, z_B \mid y) \;=\; p(z_T \mid y) \prod_{v \in B} p_v\big(z_v \mid z_{\mathrm{pa}(v)}\big), \qquad p(z_T \mid y) \;\propto\; \prod_{v\in T} p_v\big(z_v \mid z_{\mathrm{pa}(v)}\big) \prod_{v \in O} p_v\big(y_v \mid z_{\mathrm{pa}(v)}\big). \] Proof. No node of \(T \cup O\) is a descendant of a barren node: an observed one by definition, and a target one because its observed descendant would then descend from the barren node. So no kernel of \(T \cup O\) reads \(z_B\), even through a deterministic node. The barren kernels integrate to one, leaves first. ∎

So the target \(p(z_T \mid y)\) is what inference samples. Barren nodes, such as a validation source left unobserved, are drawn afterwards from their kernels given posterior draws of \(z_T\). This is the posterior predictive, provided by Posterior.predict. No argument names them: the graph does.

Definition 3 (prior, likelihood). Split the observed nodes by whether they have a target ancestor (through any node), \[ O_\theta = \{\, v \in O : \mathrm{an}(v) \cap T \neq \varnothing \,\}, \qquad O_c = O \setminus O_\theta , \] and define \[ \pi(z_T) = \prod_{v\in T} p_v\big(z_v \mid z_{\mathrm{pa}(v)}\big), \qquad L(z_T) = \prod_{v \in O_\theta} p_v\big(y_v \mid z_{\mathrm{pa}(v)}\big), \qquad C = \prod_{v \in O_c} p_v\big(y_v \mid z_{\mathrm{pa}(v)}\big). \] Then \[ p(z_T \mid y) = \frac{\pi(z_T)\, L(z_T)}{Z}, \qquad Z = \int \pi L \, d\lambda_T, \qquad p(y) = C\, Z . \] Ancestry over-approximates dependence: a node in \(O_\theta\) may have a kernel that is in fact constant in \(z_T\) (\(t \to o' \to o''\) with \(o', o''\) observed). Treating it as in \(O_\theta\) is safe, and every rule below that asks whether something depends on the target means "has a target ancestor".

Proposition 3.

  1. \(\pi\) is a normalized density on \(\mathcal Z_T\): integrate its kernels in reverse topological order, observed values held.
  2. In general \(\pi(z_T) = p(z_T \mid \mathrm{do}(z_O = y))\): the target kernels with every observed value held. When no node of \(O_\theta\) is an ancestor of a target node, \[ \pi(z_T) = p(z_T \mid y_{O_c}), \qquad L(z_T) = p(y_{O_\theta} \mid z_T, y_{O_c}), \qquad Z = p(y_{O_\theta} \mid y_{O_c}), \] and when moreover no observed node is an ancestor of a target node, \(\pi\) is the marginal law of \(z_T\) under \(P\), the prior. In every case ancestral sampling of the target kernels, with observed values held, draws from \(\pi\).
  3. Observing the nodes of \(O_c\) gives the same \(\pi\), \(L\) and \(Z\) as declaring them inputs bound to the same values; only the evidence of all observations, \(p(y) = C Z\), includes \(\log C\).

Two consequences replace the fixed= and predictive= arguments of revision 3:

  • Holding a hyperparameter at a value is observing it. When it has no target ancestor, it lands in \(O_c\), and the model is as if it were an input (Proposition 3.3). The likelihood \(L\), EKI's y and its R exclude it. A target kernel that reads it sees the held value, in \(\pi\) and in sample_prior alike. A hyperparameter with random parents is held by observing those parents too.
  • When it has a target ancestor (a variance drawn given a parameter), observing it is Bayes' rule and informs that parameter, as it should. Holding it without informing anything is a different model: one that declares it an input.

The implementation adds one deliberate limitation that is not mathematical: no target node may have a simulator among its ancestors, so that \(\pi\) is evaluated and sampled without a simulator run. It refuses sound models, such as a latent state centered on a prediction, and can be lifted when one is needed. As built in P5: nor may an observed node with no target ancestor (in \(O_c\)), whose density is the evidence's constant \(C\), computed once at condition_on; such a node would need a simulator run there. A factor's event is also wholly observed or not: observing part of a joint factor, or some of a component's labels, is refused. The way to use fewer labels is to bind fewer.

4.6 The parameters' coordinates

Each target node's value is mapped to unconstrained coordinates by its components' bijections, \(z_T = T(\theta)\), \(\theta \in \mathbb R^{D}\), in declaration order. The target density of \(\theta\) is

\[ \log p(\theta \mid y) \;=\; \log \pi\big(T(\theta)\big) + \sum_{p} \log \big|J_p(\theta_p)\big| + \log L\big(T(\theta)\big) - \log Z, \]

with \(J_p\) the Jacobian of the bijection of parameter \(p\) against its reference measure. A target kernel that is a pushforward through its components' own bijections is evaluated by its base density, exactly, with no Jacobian, as today. Posterior.log_prior is the first two terms, and Posterior.log_likelihood the third.

4.7 Failures

With \(\bot\) as in Proposition 1, an observed kernel that reads \(\bot\) gives the observed value density zero. Only the simulator outputs that target and \(O_\theta\) kernels depend on matter; an output only barren nodes read is never computed. With \(\mathcal V\) the set of \(z_T\) at which every needed output is defined, the posterior is the truncation

\[ p(z_T \mid y) \;\propto\; \pi(z_T)\, L(z_T)\, \mathbf 1\{z_T \in \mathcal V\}, \]

and \(Z = \int_{\mathcal V} \pi L\) is the probability that the needed outputs are computed and y is observed. It is not the evidence of a prior renormalized on \(\mathcal V\), which differs by \(\pi(\mathcal V)\).

Validity is defined per sample:

  • a sample of theta is valid when \(T(\theta) \in \mathcal V\) and every \(O_\theta\) kernel's log density is finite there, the second condition covering a covariance that depends on the target and fails to factor;
  • log_prior is \(\log \pi\) everywhere, finite or not by itself;
  • log_likelihood and the target are \(-\infty\) in an invalid sample.

The adapters translate the flag into each package's contract:

  • NaN for smc's count of failed runs;
  • non-finite rows of predictions for EnsKit;
  • \(-\infty\) for MCMC.

Failures that belong to no sample are refused once, at condition_on:

  • a constant that is not finite at a label in use;
  • an observed value outside its support;
  • a target or \(O_c\) kernel that is not finite at the observed values;
  • a covariance that depends on no target node and is not positive definite. Such a covariance is built and factored there, once, and shared by every draw.

7.3 What functions read

A part's functions read components and four other kinds of thing, defined in labels.py and delivered at the labels in use:

  • Coords are {dim: pandas.Index}, given to bind. Labels are unique integers or strings, or a MultiIndex whose named levels are integers, strings or datetime64[ns].
  • Inputs are declared by ArraySpecs in joint(..., inputs=) and read like components.
  • A constant is a float64 or bool xr.DataArray, finite at every label in use. Each of its dims is one of three kinds:
    • a dim of the coords (stacked dims included);
    • an element axis of a component the part declares or reads;
    • its own dim, passed whole, which the part declares in own_dims= so that a misspelled dim is still an error: a site's (x, y) on a coordinate dim, for example.
    It arrives transposed: the part's indexed_by dims first, then the part's element axes, then its other dims in its own order.
  • A label map is a one-dimensional xr.DataArray on a dim of the coords, named for its target (a dim or an element axis), whose values are the target's labels. It arrives as int64 positions into the target's labels in use.

An element axis name means one set of labels across a model: two components whose element axes share a name share its labels, which joint checks. A label map can then target an element axis by name alone.

These names are reserved and refused as component, input or axis names: theta, theta_entry, component, element and sample.

The keyword rule

A function a user writes is called with the names of its parameters that have no default. This covers a factor's law function, a deterministic's function, and a callable in a covariance spec. A function with *args, **kwargs or a positional-only parameter is refused, since what it reads cannot be read off its signature. A functools.partial's bound arguments are defaults, so they are not read. Each name a function reads is one of the following:

  • a constant or label map the part holds;
  • a component or an input. These names are the part's given components, so there is no given= argument. A GaussianSpec adds its means and the names its covariance spec reads. A builder declares what it reads.

A name that nothing declares is a ValueError at joint, and so is a name that is both a constant and a component.

  • Recognition by name. numpyro is not a dependency of the package. As built in P6:

  • A GaussianSpec has one mean, and its factor's event is one component on REAL, indexed by one dim at most, with no element axes, so its entries are its labels in order. A Gaussian over several components on different dims (correlated sources) is refused, at GaussianSpec and at noise_factor: it needs FactorSpec's joint-factor rule relaxed, per-component index shapes in the bound factor, a rule for constants read on several dims, and the permuted residual of §14, and no experiment asks for it yet. The handoff document lists it as an open item.
  • Evaluated, it is a probability.laws.GaussianLaw: a Law over the event's block holding one of pyEKI's operators (through probability/_linalg.py) and the pyeki.gauss.Gaussian of its flattened block (.gaussian). Its draws are m + L z, made by the law itself. as_law turns a pyeki.gauss.Gaussian into one.
  • A Gaussian factor is not given the probe-point checks, its support being REAL; at bind it is checked for its event shape and, when its covariance reads nothing that varies by draw (no parameter, no simulator output), for a positive-definite covariance. One that does is checked per sample, which it makes invalid where it fails, so a prior putting some mass on covariances that are not positive definite still binds.
  • "Depends on theta" is read as "is not computable from the held values" (observed values, inputs, constants, and the deterministics of them alone, no simulator). A covariance reading an observed value that itself has a target ancestor is then held, which is exact: the value is held in the conditional.

@dataclass(frozen=True)
class SumSpec(CovarianceSpec):
    r""":math:`\Sigma = \sum_i \Sigma_i` over the scope.

    ================================== =================================
    terms                              result
    ================================== =================================
    diagonals                          ``PSDDiagonal``
    any terms, inside one block        ``DensePSD`` of that block
    block-diagonal + diagonal          blockwise, the diagonal sliced
    block-diagonal, equal groupings    blockwise
    anything else                      refused

    Parameters
    ----------
    *terms : CovarianceSpec
        Positional. At least two.

    Raises
    ------
    ValueError

        over the whole event; write ``BlockDiagonalSpec(SumSpec(...))``.
    """

    scale : str

@dataclass(frozen=True)
class BlockDiagonalSpec(CovarianceSpec):
    r"""Independent groups of entries, each with its own block; evaluates to
    ``PSDBlockDiag``.

    Entries sharing their labels at *by* form a group, the scope of *block*.
    What *block* reads arrives:

    - on the event's dim: sliced to the group;
    - on a dim named like *by*: at the group's label, such as a per-site
      variance under ``by="site"``;
    - otherwise: whole.

    Parameters
    ----------
    block : CovarianceSpec
        Positional-only.
    by : str or tuple of str
        Keyword-only. A level of the event's stacked dim, the dim itself, or
        several levels.

    Raises
    ------
    ValueError
        At :meth:`ModelSpec.bind`: if *by* is not a level of the event's dim,
        or its labels are not among those of the dim named like it.
    """


@dataclass(frozen=True)
class SubmatrixSpec(CovarianceSpec):
    r""":math:`\Sigma_{ij} = S[\mu_i, \mu_j]`, a matrix component's rows and
    columns at each entry's label; evaluates to ``DensePSD``.

    Parameters
    ----------
    component : str
        Positional-only. A component on :data:`POSITIVE_DEFINITE`, ``(p, p)``.
    label_map : str
        Keyword-only. A label map :math:`\mu` from the event's dim to the
        component's first element axis.

    Raises
    ------
    ValueError
        If two entries in the scope map to one label.
    """

As built in P6:

  • Each spec is bound to its scope with the factor, at bind (which entries form which group is fixed then), and builds its operator at each draw from what the factor reads, sliced to the scope.
  • A BlockDiagonalSpec's groups must be contiguous in the event, so that the operator is the covariance in the event's order; one that is not is refused at bind. An observation dim grouped by site, sorted by site, always is. Groups are in order of first appearance; by may be several levels, or the dim itself (one entry per group); groupings nest.
  • SumSpec adds its terms as dense matrices and factors the sum once, since a term may be only semi-definite (an outer product of standard deviations). Its table's second row reads "no block-diagonal term: DensePSD over the scope", inside a block or not; blockwise sums are rewritten as BlockDiagonalSpec(SumSpec(...)).
  • DiagonalSpec's name may be a scalar's, which every entry takes; ScaledSpec's scale may be a constant as well as a component, and a component's support must keep it positive.
  • A value precondition (a positive variance, a positive-definite block) is not checked when an operator is built, as pyEKI does outside its debug mode: one that fails gives a density that is not finite. A covariance the held values fix is checked once at condition_on, one read at a draw makes that sample invalid.

7.9 Simulator

class Simulator(ABC):
    """A deterministic part computed outside JAX for a whole batch of samples:
    a simulation that may fail at some of them.

    The model calls it once per batch with the labeled values of what it
    reads, and reads which samples each output was computed at. Its outputs
    are constants to differentiation. It is real code, not a declaration.
    """

    @property
    @abstractmethod
    def name(self) -> str:
        """Its name in ``describe`` and in :class:`PosteriorEvaluation`."""

    @property
    @abstractmethod
    def given(self) -> tuple[str, ...]:
        """The components and inputs it reads."""

    @property
    @abstractmethod
    def outputs(self) -> tuple[ArraySpec, ...]:
        """The components it produces."""

    @abstractmethod
    def __call__(self, given_values: LabeledValues) -> SimulatorOutput:
        """Its outputs at every sample of a batch.

        Parameters
        ----------
        given_values : LabeledValues
            Each component and input it reads, on ``(sample, *indexed_by,
            *element axes)``, ``sample`` labeled ``0`` to ``J - 1``.

        Returns
        -------
        SimulatorOutput

        Raises
        ------
        Exception
            Whatever its machinery raises. A failure at a sample's values is
            reported in ``SimulatorOutput.valid``, never raised.
        """

    @abstractmethod
    def at(self, coords: Mapping[str, pd.Index], outputs: Sequence[str]) -> Simulator:
        """This simulator at the labels *coords*, computing only *outputs*:
        itself when both are what it was built for, a restricted copy
        otherwise. ``bind`` calls it with every output, and a posterior with
        the outputs its target and likelihood depend on, so a source only
        barren nodes read is never run.

        Raises
        ------
        ValueError
            If it cannot produce its outputs at *coords*.
        """

    def check_given(self, given_specs: Mapping[str, ArraySpec],
                    corner_values: LabeledValues) -> None:
        """Check, once, that what it reads fits it; :func:`condition_on` calls
        it. Default: no check.

        Parameters
        ----------
        given_specs : Mapping[str, ArraySpec]
            The spec of each component and input it reads.
        corner_values : LabeledValues
            What :meth:`__call__` would receive at the corner points.

        Raises
        ------
        ValueError
            If they do not fit, naming the component.
        """


@dataclass(frozen=True, eq=False)
class SimulatorOutput:
    """What one call of a :class:`Simulator` returns.

    Attributes
    ----------
    values : Mapping[str, numpy.ndarray]
        ``{output name: (J, *block)}``, ``float64``, ``NaN`` where not
        computed.
    valid : Mapping[str, numpy.ndarray]
        ``{output name: (J,)}`` bool: the output was computed at the sample
        and is finite.
    record : Any
        Kept on the evaluation for diagnostics; the model never reads it.
    """

7.10 joint, ModelSpec and binding

def joint(*parts: FactorSpec | DeterministicSpec | Simulator | ModelSpec,
          inputs: Sequence[ArraySpec] = ()) -> ModelSpec:
    """The model whose parts are *parts*, flattened, conditional on *inputs*.

    Parts may come in any order; the examples write them conditional-first,
    ``joint(likelihood, forward_model, prior)``, as ProbPipe requires.
    Declaration order fixes theta's order.

    Parameters
    ----------
    *parts : FactorSpec, DeterministicSpec, Simulator or ModelSpec
    inputs : Sequence[ArraySpec]
        Keyword-only. Input nodes: values the model is conditional on, bound
        by :meth:`ModelSpec.bind`.

    Raises
    ------
    ValueError
        If a component or input is declared twice, a part reads a name
        nothing declares, the links form a cycle, or a ``GaussianSpec``'s
        mean differs from its event in layout or units.
    """


@dataclass(frozen=True, eq=False)
class ModelSpec:
    r"""A declaration of a model: its parts and inputs, and the density they
    define,

    .. math::

        p(z \mid u) = \prod_{b\ \text{factor}} p_b(z_{B_b} \mid z_{g(b)}, u)
            \prod_{d\ \text{deterministic}} \delta\big(z_{B_d} - f_d(z_{g(d)}, u)\big).

    Made by :func:`joint`.

    Attributes
    ----------
    parts : tuple
        In declaration order.
    component_names, input_names : tuple of str
        In declaration order.
    """

    def component_spec(self, name: str) -> ArraySpec:
        """The spec of a component or input; ``KeyError`` for any other name."""

    def bind(self, *, coords: Mapping[str, Sequence[Any]],
             inputs: Mapping[str, Any] | None = None) -> FactoredDistribution:
        """The model at the labels *coords* and the input values *inputs*: one
        distribution over its random nodes.

        Parameters
        ----------
        coords : Mapping[str, Sequence]
            Keyword-only. The labels of every dim a component or input is
            indexed by; other dims are ignored, so ``site_dims.coords`` may be
            passed whole.
        inputs : Mapping[str, Any], optional
            Keyword-only. One value per declared input, a labeled
            ``xr.DataArray`` aligned by label or an array of its block shape.

        Raises
        ------
        KeyError
            If a dim is missing, or *inputs* names no declared input.
        ValueError
            If an input is missing, extra or not finite; a
            constant, label map or input lacks a label in use; a simulator
            cannot be bound (:meth:`Simulator.at`); or a check at the probe
            points fails, naming the part.
        """

    def describe(self) -> pd.DataFrame:
        """One row per part: ``class``, ``law`` (family or function name),
        ``given``, ``indexed_by``, ``provenance``."""


@dataclass(frozen=True, eq=False)
class FactoredDistribution:
    """A model at a set of labels: the joint distribution of its components,
    conditional on its inputs. Made by :meth:`ModelSpec.bind`.

    Attributes
    ----------
    spec : ModelSpec
    coords : frozendict of str to pandas.Index
    """

    def law(self, component_name: str, /, *, given: Mapping[str, ArrayLike]) -> Law:
        """The law of the factor declaring *component_name*, for one draw.

        Parameters
        ----------
        component_name : str
            Positional-only.
        given : Mapping[str, ArrayLike]
            Keyword-only. One value of its block shape for each component and
            input the factor reads.

        Returns
        -------
        Law
            A TFP distribution or an adapted EnsKit ``Gaussian``.

        Raises
        ------
        KeyError
            If no component is called *component_name*, or *given* lacks a
            name the factor reads.
        ValueError
            If a deterministic declares *component_name*.
        """

    def select(self, **selectors: Sequence[Any]) -> FactoredDistribution:
        """``spec.bind`` at fewer labels: each selector, a dim or a level of a
        stacked dim, keeps those labels everywhere.

        Raises
        ------
        TypeError, KeyError, ValueError
            As ``ParameterVector.select`` today, and as :meth:`ModelSpec.bind`.
        """

    def marginalize(self, component_names: Sequence[str]) -> FactoredDistribution:
        """The model with *component_names* integrated out by a conjugate rule:
        each one's factor, and the factor that reads it, become one factor.

        Raises
        ------
        ValueError
            If no rule applies, naming the condition that failed.
        """

    def sample(self, key: Array, n: int, *,
               component_names: Sequence[str] | None = None) -> ValuesByName:
        """``n`` ancestral draws, ``{name: (n, *block)}``.

        Parts are evaluated in topological order. A factor that reads no
        component draws ``n`` values at once with ``jax.random.fold_in(key,
        crc32(name))``; one that reads components splits that key ``n`` ways
        and draws one value per draw, as today's prior does. With
        *component_names*, only those and their ancestors are drawn, so a
        simulator runs only when one of them needs it. Where a simulator
        fails, its outputs and their descendants are ``NaN``.

        """

    def log_prob(self, values: Mapping[str, ArrayLike]) -> Array:
        """The joint log density of every factor's event,
        ``{name: (*batch, *block)} -> (*batch,)``, against each support's
        reference measure. Deterministic components are computed, running a
        simulator if one is upstream of a factor; traceable when none is.

        Raises
        ------
        KeyError
            If *values* lacks a factor's event.
        ValueError
            If *values* holds a deterministic component, which is computed,
            not given.
        """

    def describe(self) -> pd.DataFrame:
        """``spec.describe()``, with ``evaluated_by`` (``"base density"``,
        ``"change of variables"``, ``"Gaussian"`` or ``"-"``) and the block
        shapes."""

7.12 Conditioning: condition_on and Posterior

def condition_on(model: FactoredDistribution, observed: Mapping[str, Any]) -> Posterior:
    r"""Bayes' rule: *model* given the values *observed* of some random nodes.

    With :math:`O` the observed nodes, the barren nodes :math:`B` (unobserved,
    no observed descendant) are dropped, and the target is the law of the
    rest, :math:`T`,

    .. math::

        p(z_T \mid y) \propto \prod_{v \in T} p_v(z_v \mid z_{\mathrm{pa}(v)})
            \prod_{v \in O} p_v(y_v \mid z_{\mathrm{pa}(v)}).

    Observed nodes whose kernels depend on no target node contribute only a
    constant, so observing a hyperparameter at a value holds it fixed.

    Parameters
    ----------
    model : FactoredDistribution
    observed : Mapping[str, Any]
        ``{component name: value}``, every component of each observed factor;
        a labeled ``xr.DataArray`` aligned by label, or an array of the block
        shape.

    Raises
    ------
    KeyError
        If a name is not a component a factor declares, or a labeled value
        lacks a label in use.
    ValueError
        If part of a factor's event is observed, a value is not finite or
        outside its support, nothing is left to infer, a target node has a
        simulator among its ancestors, a covariance that depends on no target
        node is not positive definite, or a simulator's ``check_given``
        fails.
    """


@dataclass(frozen=True, eq=False)
class Posterior:
    r"""A model conditioned on values: the unnormalized density of its
    parameters in unconstrained coordinates,

    .. math::

        \log p(\theta \mid y) = \log \pi_\theta(\theta) + \log L(\theta) + \text{const},

    and what an inference algorithm reads from it. It holds no samples.

    Attributes
    ----------
    model : FactoredDistribution
    parameters : Layout
        The parameters' natural layout; ``parameters.unconstrained`` is
        theta's, of ``D`` entries.
    observations : Layout or None
        The layout of the observed components the likelihood depends on
        (:math:`O_\theta`), of ``N`` entries; ``None`` when there are none,
        since a layout holds at least one component (P3).
    y : jax.Array
        ``(N,)``, their values.
    observed : frozendict of str to xr.DataArray
        The observed values.
    parameter_names : tuple of str
        The target's components, :math:`T`.
    barren_names : tuple of str
        The barren nodes' components, :math:`B`, drawn by :meth:`predict`.
    constant_names : tuple of str
        Observed components with no target ancestor, :math:`O_c`: in the
        evidence, not in the likelihood.
    log_constant : float
        :math:`\log C`, their kernels' log density at the observed values;
        ``log p(y) = log Z + log_constant``.
    dimension : int
        ``D``.
    simulator_free_positions : numpy.ndarray
        ``int64``, the entries of theta with no simulator among their
        descendants.
    simulators : frozendict of str to Simulator
        Each simulator the likelihood depends on, at the outputs it depends
        on (P5).
    """

    def sample_prior(self, key: Array, n: int) -> Array:
        r"""``n`` draws of theta from :math:`\pi`, ``(n, D)``: the target kernels
        sampled ancestrally with every observed value held, so a target kernel
        that reads a held hyperparameter sees its value. No simulator runs."""

    def log_prior(self, theta: ArrayLike) -> Array:
        r""":math:`\log \pi_\theta(\theta)`, ``(..., D) -> (...)``, normalized,
        ``-inf`` where a latent factor's density is not finite; traceable."""

    def evaluate(self, theta: ArrayLike) -> PosteriorEvaluation:
        """Evaluate the target at a batch of theta, running each simulator once.

        Parameters
        ----------
        theta : ArrayLike
            ``(J, D)``, or ``(D,)`` for one sample; finite.

        Returns
        -------
        PosteriorEvaluation

        Raises
        ------
        ValueError
            If *theta* is not ``(J, D)`` or ``(D,)``, or not finite.
        """

    def log_likelihood(self, theta: ArrayLike) -> Array:
        """``evaluate(theta).log_likelihood``, ``(J,)``, and ``()`` for one
        sample, when a simulator is upstream of the likelihood; without one,
        a traced function, ``(..., D) -> (...)`` (P3, kept in P5)."""

    def log_density(self, theta: ArrayLike) -> Array:
        """``evaluate(theta).log_density``, ``(J,)``; traced without a
        simulator, as :meth:`log_likelihood`."""

    def log_density_given(self, evaluation: PosteriorEvaluation) -> Callable[[Array], Array]:
        r"""The log posterior as a function of the entries of theta that no
        simulator depends on (has among its descendants), every other entry and every simulator output held at
        *evaluation*'s: ``(J, D_free) -> (J,)``, traceable.

        Its gradient is the posterior's in those entries, which sit at
        :attr:`simulator_free_positions` of theta.
        """

    def predict(self, key: Array, theta: ArrayLike) -> tuple[ValuesByName, Mapping[str, Array]]:
        """Draws of the barren components at a batch of theta, each kernel
        sampled once per sample with the observed values held: the posterior
        predictive of what was not observed (a validation source).

        Returns
        -------
        (ValuesByName, Mapping[str, jax.Array])
            ``{name: (J, *block)}``, and per component ``(J,)`` bool, whether
            the simulator outputs it reads were computed.
        """

    def replicate(self, key: Array, theta: ArrayLike) -> tuple[ValuesByName, Mapping[str, Array]]:
        """Replicated draws of the :math:`O_\theta` components at a batch of
        theta, each from its kernel given the sample: a posterior predictive
        check of the observations. :math:`O_c` components are held, and not
        replicated. Returns as :meth:`predict`. (P5: the :math:`O_\theta`
        factors are drawn ancestrally, so one that reads another reads its
        replicate.)"""

    def simulator_inputs(self, theta: ArrayLike, simulator_name: str) -> LabeledValues:
        """What the simulator *simulator_name* reads at a batch of theta, as it
        would receive it: for running it with other reductions, a daily
        output say."""

    def natural_values(self, theta: ArrayLike) -> ValuesByName:
        """The parameters' values at theta, and those of the deterministics with
        no simulator ancestor; traceable."""

    def theta_with(self, theta: ArrayLike, values: Mapping[str, ArrayLike]) -> Array:
        r"""*theta* with the named parameters set to natural *values* through
        :math:`T^{-1}`; traceable.

        Raises
        ------
        KeyError
            If a name is not a parameter.
        ValueError
            If a value has no theta (:meth:`Layout.contains`).
        """

    def to_labeled(self, theta: ArrayLike) -> LabeledValues:
        """A batch as labeled values, batch dim ``sample``: the natural values,
        and ``"theta"`` on ``(sample, theta_entry)``. ``theta`` is a reserved
        name."""

    def gaussian_likelihood(self) -> GaussianLikelihood:
        r"""The likelihood as :math:`y \sim \mathcal N(G(\theta), R)`.

        Raises
        ------
        ValueError
            Unless the kernel of every node in :math:`O_\theta` is a
            :class:`GaussianSpec` whose covariance has no target ancestor. The
            message names the factor and the target ancestors, and suggests
            observing them at values.
        """

    def full_conditional(self, component_name: str) -> FullConditional:
        """The closed-form law of one parameter given everything else.

        Raises
        ------
        ValueError
            If no conjugate rule applies, naming the condition that failed.
        """

    def describe(self) -> pd.DataFrame:
        """One row per component and input: ``role`` (``"parameter"``,
        ``"observed"``, ``"observed, constant"``, ``"barren"``, ``"input"`` or
        ``"computed"``), and the declaring part's name and class."""

    Attributes
    ----------
    theta : jax.Array
        ``(J, D)``.
    log_prior : jax.Array
        ``(J,)``, :math:`\log \pi` everywhere, as :meth:`Posterior.log_prior`.
    log_likelihood, log_density : jax.Array
        ``(J,)``; ``-inf`` where ``valid`` is false.
    valid : jax.Array

        Every deterministic component, ``(J, *block)``. (P5: those the

    # As built in P6: GaussianLikelihood also holds ``posterior`` and

@dataclass(frozen=True, eq=False)
class FullConditional:
    """The closed-form law of one parameter given every other component.

    Attributes
    ----------

7.13 Conjugacy

Two rules are matched on the declarations, never on values. Both are optional: a model with an inverse gamma or inverse Wishart component is valid with those components as parameters, sampled jointly. The conditions are chosen narrow, for the cases this project's noise models produce. They can be widened, for a scale shared by two factors or prior constants that are parameters.

R1. Inverse gamma on a covariance scale

It applies when:

  • a component v, scalar or indexed by a dim d, has a factor whose law is inverse_gamma(shape=a, scale=b), alone or under iid_over_dim or independent_over_dim, and which reads no component;
  • exactly one part reads v, and it is a factor whose law is a GaussianSpec with covariance ScaledSpec(base, scale=v) or BlockDiagonalSpec(ScaledSpec(base, scale=v), by=d);
  • base does not depend on v.

For full_conditional, v must be a parameter and the reading factor observed or a parameter; its residual is its event value minus its mean. For group s with ns entries, residual rs = ys − ms and qs = rs⊤Rs−1rs:

marginal:  ys ~ t2a(ms, (b/a)Rs),   log p = log Γ(a + ns/2) − log Γ(a) + a log b − (ns/2) log 2π − ½ log|Rs| − (a + ns/2) log(b + qs/2)
full conditional:  vs | rest ~ IG(a + ns/2, b + qs/2)

A scalar v shared by every group gives one Student-t, with n = Σns and q = Σqs.

R2. Inverse Wishart on a covariance block

It applies when:

  • a p × p component S has a factor whose law is inverse_wishart(degrees_of_freedom=ν, scale=Ψ) and which reads no component;
  • exactly one part reads S, and it is a factor whose law is a GaussianSpec with covariance BlockDiagonalSpec(SubmatrixSpec(S, label_map=μ), by=g), with nothing added;
  • every group maps to the same q of S's labels, O.

Then SOO ~ W−1q(ν′, ΨOO), with ν′ = ν − (p − q). With n groups, residuals ri and E = Σriri⊤:

full conditional:  SOO | rest ~ W−1(ν′ + n, ΨOO + E); the rest of S drawn from its prior conditional given SOO
marginal:  log p(r1:n) = −(nq/2) log π + log Γq((ν′+n)/2) − log Γq(ν′/2) + (ν′/2) log|ΨOO| − ((ν′+n)/2) log|ΨOO + E|
Where R2 stops

R2 does not cover:

  • groups that map to different subsets of S's labels, as when sites' records are ragged;
  • a term added to the submatrix.

An exact Gibbs step for the ragged case, by data augmentation, exists but is not proposed. marginalize and full_conditional refuse both cases and say why, and joint sampling covers them.

As built in P8:

  • The marginal factor's law. The design left it unnamed. It is one of two law forms of a new module, probability.scale_mixtures: StudentTSpec(mean=, covariance=, shape=, scale=, by=None), a Student-t per group (one group without by), and MatrixStudentTSpec(mean=, by=, label_map=, degrees_of_freedom=, scale=), evaluated to StudentTLaw and MatrixStudentTLaw. They hold the prior's numbers as labeled arrays, read by label when bound, so a marginal model selected at fewer labels is the marginal of the selection, R2's rows O found again there. With GaussianSpec they are the parts module's CENTERED_LAW_SPECS: bound with their factor and checked as a Gaussian is. A user may declare one directly, as a Student-t noise model.
  • Names. The code calls R1 the scale rule and R2 the block rule, since R1 also names the removal PR.
  • Where things live. FullConditional is in posterior, as §6's module list has it; the rules are a new module, probability.conjugacy: conjugate_rule(model, name) -> ConjugateRule, which holds the matched factors, the marginal law and the full conditional's arithmetic from residuals; marginalize; InverseWishartGivenRows, R2's full conditional, the posterior on the observed rows and the prior on the rest (the inverse Wishart itself when every row is observed), unchecked so that it is NaN at a sample whose mean was not computed; and the rule names INVERSE_GAMMA_SCALE and INVERSE_WISHART. FullConditional also holds posterior.
  • Matching. R1's prior is recognized from its bound law, which is fixed because its factor reads no component: an inverse gamma alone, under Sample (iid_over_dim) or under Independent (independent_over_dim), whatever function built it; R2's is an exact InverseWishart. A scalar v under BlockDiagonalSpec(ScaledSpec(base, scale=v), by=g) takes any grouping and gives one Student-t over the event with covariance BlockDiagonalSpec(base, by=g). A v on d grouped otherwise is already refused when the model is bound.
  • Marginalizing. Names are integrated out in order, each from the model the last left; the marginal factor takes the reader's place in declaration order and keeps its constants the marginal reads; its provenance joins the reader's and the prior's. An empty list is refused. A Student-t's covariance is built per evaluation, not held at condition_on as a Gaussian's is.
  • Full conditionals. Where an evaluation's mean was not computed, the law's parameters and draws are NaN. theta_with checks a value has a theta only when it is concrete, so it stays traceable.
  • The proofs. R1's full conditional is checked against a long random-walk Metropolis chain, as planned, and against the joint density exactly. R2's is checked against the joint density exactly and against its closed-form moments, including the rows drawn from the prior given SOO, rather than a chain over a matrix.

Everything but a simulator is traced JAX. log_prior has exact gradients. log_density_given has exact gradients in the entries of theta no simulator depends on, given a simulator evaluation: noise and GP hyperparameters, and coefficients that only enter priors. def nee_night_block(time_since_epoch, standard_deviation):
    """One site's night NEE: measurement error, plus discrepancy at two timescales."""
    lag = jnp.abs(time_since_epoch[:, None] - time_since_epoch[None, :]) / DAY
    discrepancy = 0.603**2 * jnp.exp(-lag / 0.74) + 1.20**2 * jnp.exp(-lag / 57.2)
    return jnp.diag(standard_deviation**2) + discrepancy


def leaf_area_index_block(time_since_epoch, calendar_year, standard_deviation):
    """One site's LAI: the floored measurement error, plus discrepancy within each summer."""
    lag = jnp.abs(time_since_epoch[:, None] - time_since_epoch[None, :]) / DAY
    same_summer = calendar_year[:, None] == calendar_year[None, :]
    floored = jnp.maximum(standard_deviation, 0.66)
    return jnp.diag(floored**2) + 0.5**2 * jnp.exp(-lag / 30.0) * same_summer


def landtrendr_block(standard_deviation, observed):
    """One site's biomass: LandTrendr's and the carbon fraction's errors, each
    shared by every year, plus independent discrepancy."""
    relative = 0.02 / WOOD_CARBON_FRACTION
    return (jnp.outer(standard_deviation, standard_deviation)
            + relative**2 * jnp.outer(observed, observed)
            + 5.0**2 * jnp.eye(observed.shape[0]))


def soil_carbon_variance(standard_deviation, observed):
    """SoilGrids' error, plus discrepancy proportional to the stock."""
    return standard_deviation**2 + (0.25 * observed)**2

10.3 A covariate-dependent log-Gaussian field, a global parameter, and a per-site parameter

Three parameters over 200 sites:

    """log P_s ~ N(beta_0 + w_s . beta, 0.4^2), independently over sites."""

def log_capacity_process(log_capacity_intercept, log_capacity_slopes, covariates, site_locations):
    """log P ~ GP(beta_0 + w . beta, Matern-3/2, 200 km length scale, 0.4 sd)."""
    mean = log_capacity_intercept + covariates @ log_capacity_slopes

    return pushforward(field, support=POSITIVE)

14Open questions and risks

  • EnsKit is being rewritten. PRs C and D depend on its linalg, distribution and EKI layers. The interims are today's pyEKI classes, which keep their names through EnsKit's PR 1 rename. The adapter's text is kept thin until EnsKit's driver lands. Resolved 2026-10-05: the rewrite is complete; E1 and E2 move to it.
  • Correlated sources grouped by site. A GaussianSpec over two components grouped by site is not contiguous in y, and EnsKit has no permutation operator. The core permutes the residual itself. The EKI view must then hold that factor's block as one DensePSD, refused above EnsKit's dense limit.
  • Sums of covariances. SumSpec refuses a sum that would need a dense matrix over a whole event. A discrepancy shared across sites, added to per-site measurement error, would need EnsKit's LowRankUpdate; the rule is written when that case arrives.
  • Compile time for many block shapes. Each distinct block size compiles once. Hundreds of sites call for grouping equal sizes and vmapping over each group.
  • Dense block size. A dense block costs ns3, so hourly NEE over nine years at a site (about 79,000 values) must be aggregated first, as PR #69 does.
  • Nested samplers (nautilus) want a prior transform from the unit cube, which only independent one-dimensional factors have.
  • Discrete unknowns, such as an initial-condition member, lie outside theta (D13).
  • ProbPipe's failure contract. ProbPipe has no per-sample failure semantics yet; ours is the part to propose upstream at migration.
  • The core's shared names. The core cannot import conventions, and conventions must not import the core, which loads TFP. Both hold the literal "sample", and a test checks that they agree.
  • The pyEKI rename. EnsKit's PR 1 renames pyeki to enskit, and its PR 7 deletes today's gauss and eki. The upgrade step CLAUDE.md asks of every session would then break every import. The refactor's sessions upgrade pySIPNET and PyEns only, and route pyEKI through one shim; pinning pyEKI's revision for everyone is a question for Andrew (handoff document). Decided 2026-10-05: the project tracks EnsKit's main, re-pinned by E1, after which enskit is upgraded with the other companions.
  • Labels at scale. Today's coverage check is quadratic, about 2 s for 2,000 labels against 20,000 and minutes at 80,000. as_coords refuses a MultiIndex, and pandas gives datetime64[us] where the design says [ns]. P2 rewrites these.
